# Data sources

Public datasets considered for this project. A dataset is not cleared for use until its licence, coverage, and access method are filled in here.

Do not commit downloaded rasters. Put the commands that fetch a file in `scripts/`, and keep the file itself under `data/` (gitignored).

Do not put precise coordinates of candidate or undiscovered sites in this file.
